# Taha's Letter World · عالم حروف طه

A home-screen app for Taha: Arabic and English letters and words, maths to 100, memory, focus and IQ games, a daily brain workout, and short surahs of the Quran.

- `index.html` – the whole app
- `sw.js` – offline support (change `VERSION` on each update)
- `manifest.webmanifest`, `*.png` – app name and icons

Netlify publishes this repository automatically on every push to `main`.

Quran text: Tanzil.net (Quran Simple edition). Recitation streamed from EveryAyah.com and Quran.com.
